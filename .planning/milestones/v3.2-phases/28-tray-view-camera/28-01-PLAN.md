3. Update `_build_menu` to return menu with this order:
   ```python
   return pystray.Menu(
       pystray.MenuItem(
           text=lambda item: "Active" if self._active.is_set() else "Inactive",
           action=self._on_toggle,
           checked=lambda item: self._active.is_set(),
       ),
       pystray.Menu.SEPARATOR,
       pystray.MenuItem("Edit Config", self._on_edit_config),
       pystray.MenuItem(
           text=lambda item: "View Camera (Running)" if self._camera_active.is_set() else "View Camera",
           action=self._on_view_camera,
           enabled=lambda item: not self._camera_active.is_set(),
       ),
       pystray.Menu.SEPARATOR,
       pystray.MenuItem("Quit", self._on_quit),
   )
   ```

4. Add `_on_view_camera(self, icon, item)` method:
   - Set `self._camera_active` (signals detection loop to release pipeline)
   - Clear `self._active` (stops detection loop's inner while)
   - Show notification: `icon.notify("Opening camera preview...", "Gesture Keys")`
   - Build subprocess command:
     ```python
     if getattr(sys, 'frozen', False):
         cmd = [sys.executable, '--view-camera', '--config', self._config_path]
     else:
         cmd = [sys.executable, '-m', 'gesture_keys', '--view-camera', '--config', self._config_path]
     ```
   - Set `creationflags` for Windows:
     ```python
     kwargs = {}
     if sys.platform == 'win32':
         kwargs['creationflags'] = subprocess.CREATE_NO_WINDOW
     ```
   - Spawn: `proc = subprocess.Popen(cmd, **kwargs)`
   - Update menu: `icon.update_menu()`
   - Start monitor thread:
     ```python
     threading.Thread(target=self._monitor_camera_process, args=(proc,), daemon=True).start()
     ```
   - Wrap entire body in try/except. On exception: log error, clear `_camera_active`, set `_active`, notify user with "Failed to open camera preview. Check logs for details.", call `icon.update_menu()`.

5. Add `_monitor_camera_process(self, proc)` method:
   - Call `proc.wait()`
   - Clear `self._camera_active`
   - Set `self._active` (resumes detection)
   - Call `self._icon.update_menu()`
   - Call `self._icon.notify("Camera closed. Detection resumed.", "Gesture Keys")`

6. In `_detection_loop`, update the inner while condition to also check `_camera_active`:
   ```python
   while self._active.is_set() and not self._shutdown.is_set() and not self._camera_active.is_set():
       pipeline.process_frame()
   ```
   This ensures the pipeline is stopped promptly when View Camera is clicked (the `finally: pipeline.stop()` handles cleanup).

7. In `_on_quit`, also handle camera process cleanup: if `_camera_active` is set, the camera subprocess is running but we are quitting. This is fine -- the daemon monitor thread will die with the process, and the camera subprocess will notice its parent is gone or the user will close it manually. No special handling needed.
