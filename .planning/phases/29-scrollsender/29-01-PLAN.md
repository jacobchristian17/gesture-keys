    ScrollSender class design:
    - `__init__(self, scroll_speed: float = 3.0, max_ticks: int = 10, ema_alpha: float = 0.3)`:
      - Creates `self._controller = Controller()`
      - Stores config: `self._scroll_speed`, `self._max_ticks`, `self._ema_alpha`
      - Init EMA state: `self._smoothed_velocity: float = 0.0`
      - Init flag: `self._has_prev: bool = False`

    - `scroll(self, direction: Direction, velocity: float) -> None`:
      1. Apply EMA smoothing to velocity:
         - If not self._has_prev: self._smoothed_velocity = velocity; self._has_prev = True
         - Else: self._smoothed_velocity = self._ema_alpha * velocity + (1 - self._ema_alpha) * self._smoothed_velocity
      2. Compute ticks with nonlinear acceleration curve:
         - `raw = self._smoothed_velocity * self._scroll_speed`
         - `curved = math.pow(raw, 1.5)` (superlinear — slow is precise, fast is amplified)
         - `ticks = max(1, min(self._max_ticks, round(curved)))`
      3. Route direction to scroll axis:
         - Direction.UP: `self._controller.scroll(0, ticks)`
         - Direction.DOWN: `self._controller.scroll(0, -ticks)`
         - Direction.RIGHT: `self._controller.scroll(ticks, 0)`
         - Direction.LEFT: `self._controller.scroll(-ticks, 0)`

    - `reset(self) -> None`:
      - `self._smoothed_velocity = 0.0`
      - `self._has_prev = False`
